==========

    -> Hardware Asset Management (HAM)

        -> Hardware Asset Management (HAM) is the Management Of Organizations Physical Assets. 

            -> From When An Asset Is Requested 

                -> Then Procuring It 

                    -> Then Eventually Being Disposed Of 

            -> Without HAM In Place, 
            
                -> it would be hard to figure out What Assets The Company Owns 

                -> Where the assets are located 

                -> Which assets are supporting by business service or system 

                -> We would have security concerns, who is using this asset from accountability standpoint

        -> Person John (New Employee), Joining ABC Tech 

        -> Employee John Needs Laptop To Do His Work 

        -> ABC Tech, is using ServiceNow To Manage Hardware Assets

                -> John Is Joining On 1st Dec 2026

    -> Hardware Models

        -> Hardware Model is ServiceNow record that represents "Specific Hardware Product"
        and stores the Information that is "Common" To the Hardware Assets Created From That Model.

        -> A Hardware Asset represents an Individual Physical Item, belonging To Hardware Model.

        -> Typical Information Stored At Hardware Model Level is Manufacturer, Model Category, Weight, description etc  

        -> NOTE: Relationship Between Hardware Model and Hardware Assets is "One To Many", meaning 
        You Can Have Multiple Hardware Assets For Any Given Hardware Model

Class - 6
==========

    -> Consumables 

        -> Consumables are better Known as "Accessories"

        -> Consumables are the assets that are not required to be tracked while in use 
        due to their Low Value and Ease Of Replacement

        -> Consumables are tracked by Quantity Level, while they are in stock 
        and are no longer tracked once they are deployed. 

        -> Consumables Consists Of Assets Such As Cables, Adapters, Earphones, 
        Keyboards, Mouse, Webcams etc 

        -> Since Consumables are not tracked after deployment, it is not necessary 
        to do tagging for Consumables.

        -> NOTE: Consumables should be tracked when they are Purchased and kept in 
        Inventory, this ensures all asset managers have visibility over all the 
        stock of Consumables 

    -> To Create Consumables We Need Consumable Models. 

        -> Hardware Model -> Hardware Asset 

        -> Consumable Model -> Consumable Asset 

        -> A consumable model in ServiceNow defines low-cost, bulk-managed items 
        tracked by quantity rather than individual serial numbers or asset tags. 
        Common examples include keyboards, mice, cables, adapters, 
        printer cartridges, and filters.

        -> Created Consumable Model and Then Create Consumable Asset From Model 

    
    -> Configuration Items 

        -> A Configuration Item also known as CI, is an component that is 
        managed in order to deliver an IT Service. 

        -> A Configuration Item in servicenow is a record within the 
        Configuration Management Data Base (CMDB), representing 
        "Any Manageable IT Component" such as Computer, Server, 
        Application, Application Service etc 

        -> Tracking Configuration Items is must for any Organization, as it 
        allows you to track upstream and downstream dependencies that 
        support your IT Services.

        
Class - 7
==========

    -> Configuration Items 

        -> Configuration Items contain all the Configuration Information
        related to specific item, for example Configuration item of a 
        Computer asset can include Information like Hard Disk Capacity, 
        RAM Usage, IP Address, MAC Address, Installed Softwares etc 

    -> In ServiceNow, When You Create Hardware Asset, A Configuration Item 
    record is also created and linked with it. 

        -> If a CI Class is Defined at the Model Level when Creating 
        an Hardware Asset then a Configuration Item Will Automatically Be Created.

        -> If An Asset Class is Defined at the Model Level When Creating 
        a Configuration item, then a Hardware Asset Will be Created 


                Asset                           Configuration Item 
        Lenovo-Z9-Workstation      <------>     Lenovo-Z9-Workstation
            (Asset Tag)                           (HDD-RAM-IP)
        
        -> NOTE: In Most Of Organizations, Configuration Items are tracked by 
        ITOM Teams, as Configuration Items needs to be tracked to monitor 
        and ensure "Availability Of Business Services" 

        -> NOTE: IT Asset Management Team Tracks "Financial and Physical Lifecycle"
        Of The Assets. 

    
    -> Difference Between Hardware Asset and Configuration Item 

        -> An Hardware Asset is a device like Computer Or Server, which needs to 
        be tracked due to it's Financial Value To An Organization 

        -> Configuration Items Can Also Be Assets, but not Always, and these 
        are tracked as it directly affects the business services.

            -> A Configuration File is an Configuration Item, but not an Asset. 


    -> Assets                                   -> Configuration Items 

        -> Tracked For Financial Purpose            -> Tracked For Supporting Business Services

        -> Tracked From Acquisition To Disposal     -> Only Tracked When It's In Use 

        -> Have Parent / Child Relationship         -> Have Upstream and Downstream Dependencies 

        -> Financial Value Is Assigned              -> No Financial Value Is Assigned

        -> Tracked By IT Asset Team                 -> Tracked By IT Ops Team (ITOM)
